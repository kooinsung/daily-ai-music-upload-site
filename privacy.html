개인정보처리방침

시행일: 2026년 8월 22일

1. 처리 목적

Daily AI Music Upload는 사용자가 승인한 YouTube 채널에 동영상 콘텐츠를 업로드하기 위해 Google OAuth 인증을 사용합니다.

2. 처리하는 정보

앱은 Google이 발급한 OAuth 인증 토큰과 YouTube 업로드 결과에 필요한 최소한의 기술 정보를 처리할 수 있습니다. Google 계정 비밀번호는 수집하거나 저장하지 않습니다.

3. 정보의 이용 및 공유

인증 정보는 사용자가 요청한 YouTube 영상 업로드에만 이용됩니다. 개인정보를 판매하지 않으며, 법률상 의무가 있는 경우를 제외하고 제3자에게 제공하지 않습니다.

4. 보관 및 삭제

OAuth 토큰은 자동 업로드 기능을 유지하는 동안 접근이 제한된 환경에 저장됩니다. 사용자가 Google 계정의 보안 설정에서 앱 접근 권한을 철회하거나 삭제를 요청하면 더 이상 사용하지 않습니다.

5. Google API 데이터

Google API를 통해 받은 정보의 사용과 이전은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.
